# 향후 포트폴리오 소개 초안

**작업 흐름을 지키는 메모리 노치.**

Ubuntu GNOME에서 메모리 상태와 정리 후보를 확인하고, 선택한 창에 정상 닫기를 요청합니다. Archsport와 같은 노치 모션으로 필요한 정보만 펼쳐봅니다.

소개 순서: 사용 중인 RAM 확인 → 제외 이유와 후보 검토 → 요청 후 상태 변화 확인.

이 문구는 개발 목표를 소개하는 초안이다. 공개 페이지가 아니며 지금 설치 가능한 앱이라는 주장을 하지 않는다. 완성 후 실제 제품 스크린샷·검증한 GNOME 버전·지원 범위를 추가한다. 원본 리뷰/사진/성능 수치를 matci 추천사나 성과로 사용하지 않는다.
