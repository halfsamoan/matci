# 소개·배포 계획

현재 목표는 조사와 계획이며 공개 출시가 아니다. M3 실제 사용 검증 후 사용자 개인 설치 패키지→사용 가이드/설계 설명/검증 증거 정리→필요할 경우 포트폴리오 공개 순서로 진행한다.

App Store/Google Play 대상이 아니므로 listing.json, 결제, 구매 계정, 마케팅 사이트를 만들지 않는다. 사용 통계·외부 전송도 MVP에 없다. 스크린샷은 합성 데이터 또는 사용자 식별 정보가 없는 실제 장면만 사용하고 시연 여부를 명시한다.

공개가 필요해지면 이름 확인, 라이선스/asset provenance, 사용자 데이터 제외, GNOME 호환 버전, 제한 사항, 설치/제거/rollback 설명을 먼저 검수한다. 사용자에게 다른 사람이나 커뮤니티로 메시지를 보내지 않았다.
