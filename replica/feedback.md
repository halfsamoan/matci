# 피드백 조사 범위

검색에서 확인한 사용자 리뷰 발췌는 **1개 / 1출처**, 긍정 의견이다. App Store 본문 open은 실패했고 검색 결과에 보인 문구만 `reviews.csv`에 저장했다. 날짜는 Sep 20까지만 노출돼 연도·날짜 열을 비웠으며 rating도 확정하지 않았다. 원문 링크와 발췌 상태를 보존한다.

주제는 단순함/사용 편의성이다. 표본이 적고 부정 리뷰를 수집하지 못했으므로 불만 순위·시장 규모·수요·여러 사용자의 공통 요구를 주장할 수 없다. 100개나 3출처를 채운 것처럼 꾸미지 않는다. 이 발췌를 matci의 추천사로 사용하지 않는다.

별도로 S12의 개발팀 글은 메모리 귀속과 작업 중 에이전트 보호 문제를 다룬다. 이 자료는 기술 설계의 근거이며 사용자 리뷰 수에 포함하지 않는다. `fixes.md`의 Linux 차별점은 사용자 환경에 따른 제품 가설이지 리뷰 추세가 아니다.
