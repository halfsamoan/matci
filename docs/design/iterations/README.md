# matci GNOME 50.1 네이티브 시각 반복 · 2026-10-19

## 2026-10-20 v15 실루엣 후보

격리 GNOME Shell 50.1의 1600×900 가상 모니터에서 **임시 개발 복사본**에
합성 메모리·앱 상태를 넣어 촬영했다. 앱 목록과 검토 화면은 실제 앱 닫기
대상이 아니며, 사용자 세션의 안전 정책이나 입력 검증을 대신하지 않는다.

| 상태 | 실제 GJS 렌더 캡처 |
| --- | --- |
| 기본 | [09-v15-normal.png](09-v15-normal.png) |
| 선택 | [10-v15-selected.png](10-v15-selected.png) |
| 검토 | [11-v15-review.png](11-v15-review.png) |

기본 화면은 `검토 0`과 새로고침 버튼을 숨긴다. 선택 화면은 오른쪽 체크와
파란 검토 액션을 표시한다. 격리 Shell의 pick 검사에서 투명한 상단 모서리는
배경 actor를, 중앙 목과 어깨는 노치의 반응형 actor를 선택했다. 실제 사용자
세션의 100/125/150% 배율·키보드·성능 검수는 별도다.

## 2026-10-20 Pretendard와 상단 앵커 등장 모션

같은 사용자 설치 Pretendard 1.3.9를 노치 전체와 패널 숫자에 적용했다.
격리 Shell의 계산 글꼴은 노치 루트 `Pretendard 14.666px`, 패널 숫자
`Pretendard Bold 14.666px`였다. 합성 앱 세 개로 찍은 캡처다.

| 타이머 요청 시점 | 캡처 | 실제 관측 |
| --- | --- | --- |
| [20ms](05-pretendard-reveal-20ms.png) | 104×8 상단 중앙 시작 형태 | 검은 실루엣이 즉시 보임 |
| [130ms](06-pretendard-reveal-130ms.png) | 외곽 대부분 펼쳐짐 | 앱 목록은 뒤따라 나타나는 중 |
| [360ms](07-pretendard-reveal-360ms.png) | 완성 상태 | 368×309, [앱 목록](08-pretendard-apps.png)과 일치 |

시간은 GLib 타이머 요청값이며 실제 프레임 타임 측정이 아니다. 숨김 상태에서
등장할 때만 104×8 형태에서 시작한다. 열림/닫힘을 되돌릴 때는 현재
기하값에서 이어진다. 격리 실행에서 열림 후 55ms에 닫고 95ms에 다시
열었을 때, 360ms 관측에 368×306·opacity 255·visible true로 수렴했고
`JS ERROR`가 없었다. 실제 사용자 세션의 연속 클릭은 별도 입력 검수 대상이다.

1600×900 격리 GNOME Shell에서 캡처했다. 앱 목록/검토의 이름과 수치는
개발 복사본에만 넣은 합성 값이며 실제 앱 종료는 요청하지 않았다.

| 순서 | 캡처 | 수정 근거 |
| --- | --- | --- |
| 1 | [빈 목록 첫 렌더](01-empty-before-density.png) | 내용이 없어도 회색 스크롤 막대가 보임 |
| 2 | [빈 목록 재렌더](02-empty-no-scroll.png) | 짧은 목록에서 스크롤을 숨기고 불필요한 섹션 제목 제거 |
| 3 | [앱 3개](03-apps-final.png) | 처음에는 2개만 보여 목록 높이를 보정; 최종 캡처는 3개와 보호 라벨을 모두 표시 |
| 4 | [검토](04-review-final.png) | 미저장 작업 경고와 취소/닫기 요청이 구분되어 보임 |

최종 기본 표면은 어두운 색, 투명 도구 버튼, 오른쪽 검토 동작을 사용한다.
실제 창 매핑, 선택·취소, 정상 닫기 및 사용자의 GNOME 세션 입력 검수는
이 합성 캡처로 증명하지 않는다.
